While Loop

A while loop is used when the number of iterations is not known in advance. In Bash, the while loop continues to execute a block of commands as long as a specified condition is true.

Here is the syntax:

```bash
while [ condition ]
do
    # Commands to be executed as long as the condition is true
done
```

- **`condition`**: Represents the test that determines whether the loop continues or terminates.

Example:

```bash
counter=1
while [ $counter -le 5 ]
do
    echo "Iteration $counter"
    ((counter++))
done
```

This will print the same output as the previous `for` loop example.

## DevOps Example: Wait for an Application to Become Healthy

During a deployment, a script can use a `while` loop to keep checking an application's health endpoint. It waits five seconds between checks and continues until the endpoint returns a successful HTTP response.

```bash
while ! curl -fsS http://app-server/health > /dev/null 2>&1
do
    echo "Waiting for application..."
    sleep 5
done

echo "Application is healthy!"
```

- `curl -fsS` checks the health endpoint and treats HTTP error responses as failures.
- `!` keeps the loop running while the health check fails.
- `> /dev/null 2>&1` hides the response body and error output.
- `sleep 5` waits five seconds before trying again.
- When the health check succeeds, the loop ends and prints `Application is healthy!`.
