# Until Loop in Shell Scripting

## Definition

An `until` loop runs a block of commands while its condition is false. It stops when the condition becomes true.

## Syntax

```bash
until [ condition ]
do
    commands
done
```

## Example

```bash
i=1

until [ "$i" -gt 5 ]
do
    echo "$i"
    ((i++))
done
```

## Output

```
1
2
3
4
5
```

## Explanation

- `i=1` initializes the counter variable.
- `[ "$i" -gt 5 ]` checks whether `i` is greater than `5`.
- The loop continues while this condition is false.
- `echo "$i"` prints the current value of `i`.
- `((i++))` increments `i` by 1 after each iteration.
- The loop stops when `i` becomes greater than `5`.

## DevOps Example: Wait Until a Kubernetes Pod Is Ready

`kubectl wait` checks for the pod's `Ready` condition. The loop retries every five seconds until the pod becomes ready.

```bash
until kubectl wait --for=condition=Ready pod/my-app --timeout=5s > /dev/null 2>&1
do
    echo "Waiting for pod to become ready..."
    sleep 5
done

echo "Pod is ready."
```
