# Declaring and Accessing Arrays in Bash

## Definition

An **array** in shell scripting is a variable that can store multiple values
under one name. Each value is accessed using an index. In Bash, indexed arrays
start at `0`, so the first element is at index `0`.

## Purpose

Arrays help manage and process related values efficiently, without creating a
separate variable for each value.

### DevOps perspective

In DevOps, arrays are commonly used to:

- Manage multiple servers.
- Store application names.
- Keep environment lists such as development, QA, and production.
- Work with multiple Kubernetes Pods or namespaces.
- Automate deployments across multiple resources.

### Real-time example

Instead of creating a separate variable for each server:

```bash
server1="web01"
server2="web02"
server3="web03"
```

Store the server names together in an array:

```bash
servers=("web01" "web02" "web03")
```

Read the first value by using index `0`:

```bash
echo "${servers[0]}"
```

Output:

```text
web01
```

> These examples use **Bash** arrays. They are not supported by every shell,
> including POSIX `sh`.

## Declare an array

Use parentheses to create an indexed array:

```bash
servers=("web-01" "web-02" "db-01")
```

The values are separated by spaces. Quote values that may contain spaces:

```bash
tools=("Docker" "Amazon Web Services" "Terraform")
```

You can also use `declare -a` to explicitly declare an indexed array:

```bash
declare -a environments=("development" "staging" "production")
```

## Read array elements

Use `${array_name[index]}` to access one element. Bash indexes start at `0`:

```bash
echo "${servers[0]}"  # web-01
echo "${servers[1]}"  # web-02
echo "${servers[2]}"  # db-01
```

If an index has not been assigned, it expands to an empty value:

```bash
echo "${servers[5]}"
```

## Add or update an element

Assign a value to an index to add or replace that element:

```bash
servers[3]="cache-01"  # Add an element at index 3
servers[1]="web-02b"   # Replace the element at index 1
```

Array indexes do not have to be consecutive. For example, an array can have
values at indexes `0` and `3` with indexes `1` and `2` unset.

## Get the number of elements

Use `${#array_name[@]}` to get the number of assigned elements:

```bash
server_count=${#servers[@]}
echo "Number of servers: $server_count"
```

This counts assigned elements; it does not return the highest index plus one
if the array has gaps.

## Loop through an array

Use `"${array_name[@]}"` to expand each element as a separate value. Quoting
this expansion preserves spaces inside elements:

```bash
for server in "${servers[@]}"; do
    echo "Server: $server"
done
```

To loop through the indexes:

```bash
for index in "${!servers[@]}"; do
    echo "Index $index contains ${servers[$index]}"
done
```

Using `"${!servers[@]}"` is helpful when an array has gaps because it visits
only indexes that are set.

## Select part of an array

Array slicing uses this form:

```bash
${array_name[@]:start:length}
```

For example, start at index `1` and take up to two elements:

```bash
subset=("${servers[@]:1:2}")
printf '%s\n' "${subset[@]}"
```

The slice starts at index `1`; the length `2` means it includes up to two
elements. The result is a new array.

## Complete example

```bash
#!/usr/bin/env bash

# Store a list of environments in an indexed array.
environments=("development" "staging" "production")

# Print the first value (array indexes start at 0).
echo "First environment: ${environments[0]}"

# Print the number of values in the array.
echo "Environment count: ${#environments[@]}"

# Visit each value safely, including values that contain spaces.
for environment in "${environments[@]}"; do
    echo "Deploying to: $environment"
done
```

## Common mistakes

- **Starting at index 1:** Bash indexed arrays start at index `0`.
- **Leaving array expansions unquoted:** use `"${array[@]}"` to preserve
  elements containing spaces.
- **Using `${#array}` for the number of elements:** use
  `${#array[@]}` instead.
- **Assuming arrays work in every shell:** use Bash to run Bash array scripts.
