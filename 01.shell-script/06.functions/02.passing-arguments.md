# Passing Arguments to Functions
## Defination
Passing arguments to a function means providing input values to a function when it is called. This makes the function flexible and reusable because it can perform the same task using different input values.

## Purpose

> The purpose of passing arguments to functions is to make functions dynamic
> and reusable. Instead of hardcoding values inside a function, pass different
> inputs as arguments so the same function can be used for multiple tasks.
> This reduces code duplication and makes automation scripts more flexible
> and maintainable.

### DevOps Perspective

In DevOps, we often manage multiple:

- Servers
- Services
- Applications
- Docker containers

Instead of creating separate functions for each resource, create one function
and pass the required value as an argument.

## Read arguments inside a function

Inside a Bash function, positional parameters refer to the values passed in:

| Parameter | Meaning |
| --- | --- |
| `$1` | First argument |
| `$2` | Second argument |
| `$3` | Third argument |
| `$#` | Number of arguments |
| `"$@"` | All arguments, kept as separate values |

Example:

```bash
greet_person() {
    echo "Hello, $1!"
}

greet_person "Mina"
```

Output:

```text
Hello, Mina!
```

The text `"Mina"` is the first argument, so the function reads it as `$1`.

## Pass more than one argument

```bash
make_label() {
    echo "$1: $2"
}

make_label "Environment" "development"
```

Output:

```text
Environment: development
```

`$1` is `Environment` and `$2` is `development`.

## Handle every argument safely

Use `"$@"` to loop over all arguments without splitting values that contain
spaces:

```bash
print_items() {
    for item in "$@"; do
        echo "Item: $item"
    done
}

print_items "first item" "second item"
```

Output:

```text
Item: first item
Item: second item
```

Quoting the call arguments and using `"$@"` helps preserve each argument as one
value.

## Check how many arguments were provided

Use `$#` to check the number of arguments. This example requires exactly one:

```bash
greet_person() {
    if [ "$#" -ne 1 ]; then
        echo "Usage: greet_person NAME" >&2
        return 1
    fi

    echo "Hello, $1!"
}

greet_person "Saikiran"
```

`>&2` sends the usage message to standard error, and `return 1` reports that
the function could not complete as requested. The function's status is
explained in [Returning values from functions](./03.returning-values.md).
