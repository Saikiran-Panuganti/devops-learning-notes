# Passing Arguments to Bash Functions

Arguments are values supplied when a function is called. They let one function
work with different input instead of relying on fixed values.

## Read arguments inside a function

Inside a Bash function, positional parameters refer to the values passed in:

| Parameter | Meaning |
| --- | --- |
| `$1` | First argument |
| `$2` | Second argument |
| `$3` | Third argument |
| `$#` | Number of arguments |
| `"$@"` | All arguments, kept as separate values |

Example:

```bash
greet_person() {
    echo "Hello, $1!"
}

greet_person "Mina"
```

Output:

```text
Hello, Mina!
```

The text `"Mina"` is the first argument, so the function reads it as `$1`.

## Pass more than one argument

```bash
make_label() {
    echo "$1: $2"
}

make_label "Environment" "development"
```

Output:

```text
Environment: development
```

`$1` is `Environment` and `$2` is `development`.

## Handle every argument safely

Use `"$@"` to loop over all arguments without splitting values that contain
spaces:

```bash
print_items() {
    for item in "$@"; do
        echo "Item: $item"
    done
}

print_items "first item" "second item"
```

Output:

```text
Item: first item
Item: second item
```

Quoting the call arguments and using `"$@"` helps preserve each argument as one
value.

## Check how many arguments were provided

Use `$#` to check the number of arguments. This example requires exactly one:

```bash
greet_person() {
    if [ "$#" -ne 1 ]; then
        echo "Usage: greet_person NAME" >&2
        return 1
    fi

    echo "Hello, $1!"
}

greet_person "Mina"
```

`>&2` sends the usage message to standard error, and `return 1` reports that
the function could not complete as requested. The function's status is
explained in [Returning values from functions](./03.returning-values.md).
