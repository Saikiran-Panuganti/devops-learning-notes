# Bash Functions

A function is a named group of commands. You can call it whenever you need those
commands, instead of writing them repeatedly. Functions help make scripts easier
to read, reuse, and maintain.

> These examples use **Bash**. Start a Bash script with `#!/usr/bin/env bash`
> and run it with `bash script.sh`.

## Define and call a function

Define a function before the script reaches its first call:

```bash
greet() {
    echo "Hello! Welcome to Bash."
}

greet
```

The function definition gives the commands a name. The line `greet` runs those
commands. In Bash, call a function by writing its name; do not add parentheses
to the call.

Output:

```text
Hello! Welcome to Bash.
```

## A practical example

This function prints a message for a particular task:

```bash
show_backup_message() {
    echo "The backup is starting."
}

echo "Preparing..."
show_backup_message
echo "You can add the backup commands here."
```

Functions can be called more than once:

```bash
show_backup_message
show_backup_message
```

Put related functions near the beginning of a script, then put the main steps
that call them below. This is a common style because readers can find the
available functions before seeing how the script uses them.

## Functions can receive input

You can pass values when you call a function. Inside the function, `$1` means
the first value, `$2` means the second, and so on:

```bash
greet_person() {
    echo "Hello, $1!"
}

greet_person "Mina"
```

Output:

```text
Hello, Mina!
```

## Variables inside functions

In Bash, variables are global by default, including variables assigned inside a
function. Use `local` when a variable is only needed by that function:

```bash
describe_file() {
    local file_name="$1"
    echo "The file is: $file_name"
}

describe_file "notes.txt"
```

Here, `file_name` is local to `describe_file`. The function can still read
global variables, but using `local` for temporary values helps avoid
accidentally changing variables elsewhere in the script.

## Functions and return values

In Bash, `return` sets a function's **exit status**. It is not a way to return
text or a general number. Use `echo` (or another output command) when you want
to produce text, and use the function's exit status to report success or
failure.

## Common beginner mistakes

- **Calling a function before its definition has run:** define it before the
  first call in a script.
- **Writing parentheses when calling it:** use `greet`, not `greet()`.
- **Assuming function variables are automatically local:** declare temporary
  variables with `local`.
- **Using `return` for a calculation result:** `return` is for status codes;
  use printed output to pass back a value.
- **Forgetting to quote values:** quote arguments such as `"$1"` when using
  them as a single value, especially if they may contain spaces.
