# Loops in Linux

## 1. For Loop

A for loop is used when the number of iterations is known or fixed. In Bash, the for loop is used to iterate over a sequence of values.

```bash
for variable in sequence
do
    # Commands to be executed for each iteration
done
```

- **`variable`**: Represents the loop variable that takes each value in the specified sequence.
- **`sequence`**: Can be a range of numbers, a list of items, or the output of a command.

Example:

```bash
for i in {1..5}
do
    echo "Iteration $i"
done
```

This will print:

```
Iteration 1
Iteration 2
Iteration 3
Iteration 4
Iteration 5
```

## Example

```bash
for i in 1 2 3 4 5
do
    echo $i
done
```

## Output

```
1
2
3
4
5
```

## Explanation

- `i` is the loop variable.
- The loop iterates through the values `1`, `2`, `3`, `4`, and `5`.
- During each iteration, the current value is assigned to `i`.
- `echo $i` prints the value of `i`.
- The loop ends after all values have been processed.
