# Loop Control Statements in Linux

Loop control statements change the normal flow of a loop. In Bash, `break` exits a loop, while `continue` skips the rest of the current iteration and proceeds to the next one.

## 1. Break Statement

The `break` statement exits a loop as soon as its condition is met.

```bash
while [ condition ]
do
    if [ some_condition ]
    then
        break
    fi
done
```

- **`condition`**: Determines whether the loop continues.
- **`some_condition`**: When true, causes `break` to exit the loop.

### Example

```bash
counter=1
while [ "$counter" -le 10 ]
do
    echo "Iteration $counter"
    if [ "$counter" -eq 5 ]
    then
        break
    fi
    ((counter++))
done
```

This prints iterations 1 through 5, then exits the loop.

## 2. Continue Statement

The `continue` statement skips the remaining commands in the current iteration and moves on to the next iteration.

```bash
while [ condition ]
do
    if [ some_condition ]
    then
        continue
    fi
    # Commands run when the condition is not met
done
```

- **`condition`**: Determines whether the loop continues.
- **`some_condition`**: When true, causes `continue` to skip the rest of the current iteration.

### Example

```bash
for i in {1..5}
do
    if [ "$i" -eq 3 ]
    then
        continue
    fi
    echo "Iteration $i"
done
```

This prints all iterations except iteration 3.

## Conclusion

Use `break` to exit a loop early and `continue` to skip selected iterations. These statements provide more control over loop execution.
