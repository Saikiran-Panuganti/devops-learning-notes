# Conditions in Shell Scripting

Conditions let a script choose which commands to run based on whether a test succeeds. The examples below use familiar everyday situations.

## Basic syntax

```bash
if condition; then
    commands
elif another_condition; then
    commands
else
    commands
fi
```

## 1. `if` statement

An `if` statement runs its body only when the condition is true.

**Example:** Take an umbrella if it is raining.

```bash
#!/usr/bin/env bash

WEATHER="rainy"

if [ "$WEATHER" = "rainy" ]; then
    echo "Take an umbrella"
fi
```

If the weather is not rainy, the script does nothing.

## 2. `if-else` statement

Use `else` to run a different block when the condition fails.

**Example:** Decide whether to bring a jacket based on the temperature.

```bash
#!/usr/bin/env bash

TEMPERATURE=15

if [ "$TEMPERATURE" -lt 20 ]; then
    echo "Bring a jacket"
else
    echo "A jacket is not needed"
fi
```

The `else` block runs when the temperature is 20 or higher.

## 3. `if-elif-else` statement

Use `elif` to test multiple conditions in order. The first successful condition determines which block runs.

**Example:** Choose a message based on a test score.

```bash
#!/usr/bin/env bash

SCORE=85

if [ "$SCORE" -ge 90 ]; then
    echo "Excellent"
elif [ "$SCORE" -ge 70 ]; then
    echo "Good job"
else
    echo "Keep practicing"
fi
```

Output:

```text
Good job
```

- A score of 90 or higher prints “Excellent.”
- A score from 70 through 89 prints “Good job.”
- A score below 70 prints “Keep practicing.”

## 4. Nested `if` statement

A nested `if` places one conditional inside another. The inner check runs only when the outer check succeeds.

**Example:** Decide whether to go to the park on the weekend.

```bash
#!/usr/bin/env bash

DAY="Saturday"
WEATHER="sunny"

if [ "$DAY" = "Saturday" ]; then
    echo "It's the weekend"

    if [ "$WEATHER" = "sunny" ]; then
        echo "Go to the park"
    else
        echo "Stay home and relax"
    fi
else
    echo "It's a weekday"
fi
```

The weather check happens only when the day is Saturday.

## Quick reminders

- Use `then` after the condition and close each conditional with `fi`.
- A command's exit status can be tested directly: `if command; then ...`.
- Quote variable expansions in tests.
