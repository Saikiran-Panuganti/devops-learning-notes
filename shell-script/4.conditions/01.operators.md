# Operators Used in Conditions (Bash)

Operators let you compare numbers and strings, test files, and combine conditions in Bash.

## A. Numeric comparison operators

Use these operators to compare integer values inside `[ ... ]`.

| Operator | Meaning | Example |
| --- | --- | --- |
| `-eq` | Equal to | `[ "$a" -eq "$b" ]` |
| `-ne` | Not equal to | `[ "$a" -ne "$b" ]` |
| `-gt` | Greater than | `[ "$a" -gt "$b" ]` |
| `-lt` | Less than | `[ "$a" -lt "$b" ]` |
| `-ge` | Greater than or equal to | `[ "$a" -ge "$b" ]` |
| `-le` | Less than or equal to | `[ "$a" -le "$b" ]` |

These operators expect integer values. Validate values that come from user input or external commands before comparing them.

## B. String comparison operators

| Operator | Meaning | Example |
| --- | --- | --- |
| `=` | Strings are equal | `[ "$status" = "SUCCESS" ]` |
| `!=` | Strings are not equal | `[ "$status" != "SUCCESS" ]` |
| `-z STRING` | String is empty | `[ -z "$name" ]` |
| `-n STRING` | String is not empty | `[ -n "$name" ]` |

**Example:** Check whether a deployment succeeded.

```bash
#!/usr/bin/env bash

STATUS="SUCCESS"

if [ "$STATUS" = "SUCCESS" ]; then
    echo "Deployment completed"
else
    echo "Deployment failed"
fi
```

## C. File test operators

| Operator | Meaning | Example |
| --- | --- | --- |
| `-f PATH` | Path exists and is a regular file | `[ -f "$PATH" ]` |
| `-d PATH` | Path exists and is a directory | `[ -d "$PATH" ]` |
| `-e PATH` | Path exists | `[ -e "$PATH" ]` |
| `-r PATH` | Path exists and is readable | `[ -r "$PATH" ]` |
| `-w PATH` | Path exists and is writable | `[ -w "$PATH" ]` |
| `-x PATH` | Path exists and is executable | `[ -x "$PATH" ]` |

**Example:** Check that a configuration file exists and can be read.

```bash
#!/usr/bin/env bash

CONFIG_FILE="/etc/nginx/nginx.conf"

if [ -f "$CONFIG_FILE" ] && [ -r "$CONFIG_FILE" ]; then
    echo "Configuration file exists and is readable"
else
    echo "Configuration file is missing or unreadable"
fi
```

## D. Logical operators

Logical operators combine conditions. In Bash, `&&` and `||` can connect separate commands or test expressions; `!` negates a condition.

| Operator | Meaning |
| --- | --- |
| `&&` | AND — both conditions must succeed |
| `||` | OR — the next condition is used if the first fails |
| `!` | NOT — reverses a condition's result |

**Example:** Check that a user meets an age requirement and is from India.

```bash
#!/usr/bin/env bash

AGE=25
COUNTRY="India"

if [ "$AGE" -ge 18 ] && [ "$COUNTRY" = "India" ]; then
    echo "Both conditions are true"
fi
```

For a Bash conditional expression, `[[ ... ]]` also supports `&&`, `||`, and `!`:

```bash
if [[ "$AGE" -ge 18 && "$COUNTRY" == "India" ]]; then
    echo "Both conditions are true"
fi
```

Quote variable expansions, and choose numeric comparison operators for numbers and string comparison operators for text.
