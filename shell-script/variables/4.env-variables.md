# Environment Variables

## What are environment variables?

Environment variables are named values provided to programs by the operating system or parent process. Scripts can use them for configuration instead of hardcoding environment-specific values.

## Common environment variables

| Variable | Purpose | Example |
| --- | --- | --- |
| `HOME` | Current user's home directory | `/home/ubuntu` |
| `USER` | Commonly contains the current username | `ubuntu` |
| `PATH` | Directories searched for commands | `/usr/local/bin:/usr/bin:/bin` |
| `PWD` | Current working directory | `/home/ubuntu/scripts` |
| `SHELL` | User's configured login shell | `/bin/bash` |

Values vary by system and user. `USER` and `SHELL` are commonly set environment variables, not special Bash parameters.

## Display environment information

```bash
#!/bin/bash

echo "Current user: $USER"
echo "Home directory: $HOME"
echo "Current directory: $PWD"
echo "Shell: $SHELL"
```

**DevOps use:** These values can help a script identify the user and working directory it is running under. Do not assume they are identical across machines, containers, or CI/CD runners.

## Temporary and Permanent Environment Variables in Linux

Environment variables store configuration values used by shell commands, scripts, and applications.

### 1. Temporary Environment Variables

Temporary variables are available only for the current shell session, or for a single command if assigned inline. They are lost when the shell session ends.

Example 1: Temporary variable in the current shell

```bash
export APP_ENV="dev"

echo "$APP_ENV"
```

Output:

```text
dev
```

Example 2: Variable for a single command

```bash
APP_ENV="testing" bash -c 'echo "$APP_ENV"'
```

Output:

```text
testing
```

Here, `APP_ENV` is available to that command and its child processes, but it is not set in the parent shell.

### 2. Permanent Environment Variables

Permanent variables are configured in a shell startup file so they can be set automatically in future shell sessions.

For Bash, common files are `~/.bashrc` and `~/.profile`.

Example: Set a permanent variable

Step 1: Open the Bash configuration file.

```bash
vi ~/.bashrc
```

Step 2: Add this line at the end.

```bash
export APP_ENV="production"
```

Step 3: Apply the change to the current shell.

```bash
source ~/.bashrc
```

Step 4: Verify it.

```bash
echo "$APP_ENV"
```

Output:

```text
production
```

The variable will be set automatically in future Bash sessions that read this configuration file.
