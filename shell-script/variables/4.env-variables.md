# Environment Variables

## What are environment variables?

Environment variables are named values provided to programs by the operating system or parent process. Scripts can use them for configuration instead of hardcoding environment-specific values.

## Common environment variables

| Variable | Purpose | Example |
| --- | --- | --- |
| `HOME` | Current user's home directory | `/home/ubuntu` |
| `USER` | Commonly contains the current username | `ubuntu` |
| `PATH` | Directories searched for commands | `/usr/local/bin:/usr/bin:/bin` |
| `PWD` | Current working directory | `/home/ubuntu/scripts` |
| `SHELL` | User's configured login shell | `/bin/bash` |

Values vary by system and user. `USER` and `SHELL` are commonly set environment variables, not special Bash parameters.

## Display environment information

```bash
#!/bin/bash

echo "Current user: $USER"
echo "Home directory: $HOME"
echo "Current directory: $PWD"
echo "Shell: $SHELL"
```

**DevOps use:** These values can help a script identify the user and working directory it is running under. Do not assume they are identical across machines, containers, or CI/CD runners.

## Pass an environment variable to a script

Export a variable in the current shell before starting the script:

```bash
export APP_ENV="dev"
bash deploy.sh
```

`deploy.sh` can then read the variable:

```bash
#!/bin/bash

echo "Deploying application to: $APP_ENV"
```

The exported value is available to the script and its child processes. It is not automatically saved for future terminal sessions.

## Temporary and persistent environment variables

### Temporary

An export made in a terminal applies to that shell and programs started from it. It is usually lost when that shell or login session ends. A one-command assignment applies only to that command:

```bash
APP_ENV="dev" bash deploy.sh
```

### Persistent

To make a variable available in future sessions, add its export to an appropriate shell startup file. For Bash, `~/.bashrc` is commonly used for interactive shells; `~/.profile` is commonly used for login sessions. The exact file depends on how the shell or session starts.

```bash
export APP_ENV="dev"
```

Add that line to the relevant file, then start a new session or reload the file, for example with `source ~/.bashrc`.

System-wide settings can be configured by an administrator through files such as `/etc/environment` or scripts under `/etc/profile.d/`. The mechanism and syntax depend on the system.

> Persistent environment variables are **not stored in `/bin`**. `/bin` contains executable programs; shell startup files and system environment configuration files are used to configure environment variables.
